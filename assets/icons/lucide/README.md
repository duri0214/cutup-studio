# Lucide Icons

This directory contains SVG icons based on [Lucide](https://lucide.dev/).
They are bundled locally so Cutup Studio does not fetch icons at runtime.
Their stroke color is set to white so the application can tint them for each control.

Source: <https://github.com/lucide-icons/lucide/tree/main/icons>
