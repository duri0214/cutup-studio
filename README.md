# cutup-studio

ローカルの動画・音声から使いたい区間を登録し、GUIDEに沿った構成を作るデスクトップアプリです。素材ファイルはコピーしません。

## 入力と出力

```text
入力: 素材フォルダ + 登録した区間 + GUIDE
  ↓
カタログ: material-catalog.sqlite
  ↓
出力: composition-manifest.json
```

- 入力の素材フォルダには、MP4などの動画・音声を入れます。
- カタログは、その素材と区間の情報を次回も使えるように保存します。
- `composition-manifest.json` は、選んだ素材の順番・パス・開始終了時刻を記録する構成の指示書です。動画や音声は含みません。

## 起動

Rust を導入してから実行します。

```powershell
cargo run
```

## 使い方

1. 最初に選びます。
   - `NEW`: 動画・音声が入った素材フォルダを選ぶ
   - `OPEN`: 前回作った `material-catalog.sqlite` を選ぶ
   - `DEMO`: 同梱素材で試す
2. 素材を走査したら、`区間を登録` で素材、開始・終了時刻、検索語、役割を保存します。時刻は外部プレイヤーで確認して入力します。
3. GUIDEに `役割: 探したい語句` を入力して候補を生成します。
4. 候補を順番に選び、`SAVE MANIFEST` で構成の指示書 `composition-manifest.json` を保存します。保存ダイアログは素材フォルダから開きます。

例:

```text
導入: テッカマン
つなぎ: 驚き 反応
```

## 素材カタログ

素材カタログは、素材フォルダごとの `material-catalog.sqlite` ファイルです。動画や音声ではなく、次の情報を覚えます。

| 種類 | 保存するもの |
| --- | --- |
| 素材 | フォルダ内のファイル、内容を確かめるための指紋、利用できるかどうか |
| 区間 | 素材内の開始・終了時刻 |
| 区間の情報 | 文字起こし、検索語、タグ、役割、メモ |

素材を追加・変更・移動・削除した後は、更新アイコンで再走査します。

- 同じパスの素材内容が変わると、その区間は「要確認」になります。
- 素材を移動・削除すると、以前の素材と区間は「利用不能」になります。
- 利用不能・要確認の区間は候補に使いません。
- 元の場所に同じ素材を戻すと、以前の区間を再び使えます。

アプリが移動先を勝手に探したり、素材をコピーしたりはしません。カタログとして開けるのは、このアプリが作成したSQLiteファイルだけです。

## いましないこと

- 動画・音声の再生
- 長さ・コーデックの確認
- 文字起こし、タグ、区間の自動作成
