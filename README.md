# cutup-studio

完成済みの動画・音声素材に検索語句・タグ・役割を登録し、GUIDEに沿った構成を作るデスクトップアプリです。素材ファイルはコピーしません。

## 入力と出力

```text
入力: 基準フォルダ（materials/） + 素材に登録した情報 + GUIDE
  ↓
カタログ: material-catalog.sqlite
  ↓
構成: 候補から素材を選ぶ
```

- 基準フォルダの `materials/` に、MP4やWAVなどの素材を入れます。`materials/` は空でも構いません。
- カタログは、素材と検索語句・タグ・役割を次回も使えるように保存します。将来はローカルLLMが素材の言葉を読み取り、この情報を自動で登録します。
- 構成レシピの保存・復元と、動画・音声の調理・レンダリングは後続の対応です。

## 起動

Rust を導入してから実行します。

```powershell
cargo run
```

## 使い方

1. 最初に選びます。
   - `NEW`: `materials/` がある基準フォルダを選ぶ。そこに固定名の `material-catalog.sqlite` を作る
   - `OPEN`: 前回使った基準フォルダを選ぶ。固定名の `material-catalog.sqlite` を開く
   - `DEMO`: 同梱素材で試す
2. 素材を走査したら、仮組みとして `素材の情報を登録` で素材に入っている言葉、タグ、役割を保存します。将来はローカルLLMがこの工程を自動化します。素材ファイル1本が、そのまま候補の単位です。
3. GUIDEに `役割: 探したい語句` を入力し、表示された候補から素材を選びます。

例:

```text
導入: テッカマン
つなぎ: 驚き 反応
```

## 素材カタログ

素材カタログは、基準フォルダごとの固定名 `material-catalog.sqlite` ファイルです。名前は変更しません。動画や音声ではなく、次の情報を覚えます。

| 種類 | 保存するもの |
| --- | --- |
| 素材 | フォルダ内に現在あるファイル、内容を確かめるための指紋 |
| 素材の情報 | 検索語句、タグ、役割、メモ |

素材を追加・変更・移動・削除した後は、OPENで基準フォルダを開き直します。

- 同じパスの素材内容が変わると、その素材は「要確認」になります。
- 同じ内容の素材を移動・リネームしたときは、移動先が一つだけなら情報を引き継ぎます。
- 素材を削除すると、その素材のカタログ情報も削除されます。
- 要確認の素材は候補に使いません。

アプリが素材をコピーすることはありません。カタログとして開けるのは、このアプリが作成したSQLiteファイルだけです。

この変更より前の「区間」カタログは開けません。古い `material-catalog.sqlite` を別名にしてから、`NEW` で作り直してください。

## いましないこと

- 動画・音声の再生
- 長さ・コーデックの確認
- 文字起こし、タグの自動作成

## DEMO

`DEMO` は `demo/` を基準フォルダとして使います。日本語の合成音声で作った完成済みWAV素材10本を使えます。素材一覧は [demo/README.md](demo/README.md) を参照してください。

## 開発

```powershell
cargo test
cargo fmt --all -- --check
cargo clippy --all-targets --all-features -- -D warnings
```

実装は `src/`、開発ルールは `.codex/` にあります。

### 素材から書き出しまで

1. **01 / MATERIAL CATALOG**: 素材の情報は手入力できます。任意の「解析」では、FFmpeg が素材を音声に変換し、Whisper が文字起こしします。Ollama を選ぶと、その文字から説明候補を作ります。解析結果は確認・修正用で、現在は検索に自動反映されません。
2. **02 / COMPOSITION GUIDE**: 登録した情報を使って候補を探し、素材を選びます。
3. **03 / COMPOSITION**: 選択と順番を保存し、必要に応じて FFmpeg で素材全体を連結して WAV に書き出します。

FFmpeg は 01 の解析と 03 の書き出しの両方で使います。どちらも PATH から自動検出します。Whisper と Ollama は書き出しには不要です。いずれも通常の起動や手入力には不要です。

### 構成の WAV 書き出し

FFmpeg は別途導入します。導入方法は [ローカル AI のセットアップ](src/infra/local_ai/README.md) の FFmpeg の項を参照してください。PATH が通っていれば自動検出します。見つからない場合は導入手順に従って PATH を設定し、アプリを再起動してください。

02 で各素材を選び、03 の「保存」で構成を保存してから「WAVを書き出す」を押し、保存先を指定します。保存済みの全スロットが対象です。音声を 48 kHz・ステレオの PCM WAV に変換してファイル単位で順番に連結します。区間指定は未対応です。音声がない素材や壊れた素材はエラーになります。既存の書き出し先は上書きできます。使用中の素材は書き出し先に指定できません。
