# DEMO素材

`demo/` はアプリの `DEMO` ボタンが使う素材ルートです。`materials/` には、言葉ごとに完成したWAV素材を10本入れています。DEMOは初回だけ、このフォルダ直下に `material-catalog.sqlite` を作ります。このSQLiteはローカル作業データなのでGit管理しません。

| 素材 | 話す言葉 | 役割 |
| --- | --- | --- |
| `01-tekkaman.wav` | テッカマン | 導入 |
| `02-ringo.wav` | りんご | つなぎ |
| `03-ringo-ringo.wav` | りんご りんご | 反復 |
| `04-takoyaki.wav` | たこやき | つなぎ |
| `05-sugoi.wav` | すごい | 反応 |
| `06-yabai.wav` | やばい | 反応 |
| `07-ikuze.wav` | いくぜ | 展開 |
| `08-nani.wav` | なに | 反応 |
| `09-don.wav` | どん | 効果 |
| `10-owatta.wav` | おわった | 終わり |

外部の映像・音声素材は含めません。すべてWindows標準の日本語合成音声で、このDEMO用に生成した発話です。

現在の仮組みでは、表の「話す言葉」と「役割」を `素材の情報を登録` へ手入力して使います。後続のローカルLLMは、この入力を自動化するための機能です。
