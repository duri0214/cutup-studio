# DEMO素材

`demo/` はアプリの `DEMO` ボタンが使う素材ルートです。DEMOは初回だけ、このフォルダ直下に `material-catalog.sqlite` を作ります。このSQLiteはローカル作業データなのでGit管理しません。

## 表現用の素材と組み合わせ

| 素材 | 言葉 | 役割 | 出典と条件 |
| --- | --- | --- | --- |
| `11-konnichiwa.wav` | こんにちは | 導入 | Fukujinzuke による実際の発音録音。[原本・作者・ライセンス](https://commons.wikimedia.org/wiki/File:LL-Q5287_%28jpn%29-Fukujinzuke-%E3%81%93%E3%82%93%E3%81%AB%E3%81%A1%E3%81%AF.wav)、[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。ファイル名のみ変更、音声は無加工。再配布・改変時は作者表示、ライセンスへのリンク、変更の明示が必要。 |

例えば実際の声の「こんにちは」の直後に合成音声の「テッカマン」、さらに「なに」を並べると、自然な挨拶から突然の名前と疑問へ切り替わる声色の違いを楽しめます。アプリで `DEMO` を開き、各素材の「編集」で下記の言葉と役割を登録・保存し、02 で順に `導入` / `こんにちは`、`導入` / `テッカマン`、`反応` / `なに` を検索して選択します。03 の順序で構成を確認できます。アプリ内再生は未対応なので、音を聴くには各 WAV を外部プレイヤーで順に再生するか、FFmpeg 導入後に 03 の「WAVを書き出す」を使います。基本の登録・検索・構成に外部ツールは不要です。

同梱しない候補: [Freesound の girl voice answering phone](https://freesound.org/people/vanceparley/sounds/412709/) は電話に応答する実声で CC0、ダウンロードにはログインが必要です。挨拶への別の反応として利用できます。作品由来の私有素材は自身の端末に置き、権利と利用条件を各自で確認してください。原素材を受け渡す必要はありません。

## 検索・解析の再現用素材

| 素材 | 話す言葉 | 役割 |
| --- | --- | --- |
| `01-tekkaman.wav` | テッカマン | 導入 |
| `02-ringo.wav` | りんご | つなぎ |
| `03-ringo-ringo.wav` | りんご りんご | 反復 |
| `04-takoyaki.wav` | たこやき | つなぎ |
| `05-sugoi.wav` | すごい | 反応 |
| `06-yabai.wav` | やばい | 反応 |
| `07-ikuze.wav` | いくぜ | 展開 |
| `08-nani.wav` | なに | 反応 |
| `09-don.wav` | どん | 効果 |
| `10-owatta.wav` | おわった | 終わり |

上の10本は Windows 標準の日本語合成音声で、このDEMO用に生成した発話です。外部ツールを使う実環境テストの条件は [ローカル AI のセットアップ](../src/infra/local_ai/README.md) を参照してください。通常の自動テストには Ollama、FFmpeg、Whisper は不要です。

表の「話す言葉」と「役割」は素材の「編集」で手入力して保存できます。
