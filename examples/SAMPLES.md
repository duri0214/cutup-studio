# 同梱サンプル素材

`materials/` には、カタログ走査・区間登録・manifest 作成の確認用 MP4 を10本収録しています。映像本体の自動解析や再生はアプリの対象外です。

- `01`〜`08`: ConvertICO の MP4 テスト素材。テスト、デモ、チュートリアル、バグ報告、教育用途で利用可能・帰属不要です。再販売は不可です。出典: <https://convertico.com/samples/mp4/>
- `09-big-buck-bunny.mp4`: Big Buck Bunny の10秒テスト素材。CC BY 3.0。出典: <https://test-videos.co.uk/vids/bigbuckbunny/mp4/h264/360/Big_Buck_Bunny_360_10s_1MB.mp4>
- `10-flower.mp4`: MDN の CC0 花素材。出典: <https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4>

実作品へ使う場合は、各素材の利用条件をあらためて確認してください。
