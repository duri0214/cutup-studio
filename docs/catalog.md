# 素材カタログ

## カタログとは

素材カタログは、選んだ素材フォルダ用の `material-catalog.sqlite` ファイルです。

動画や音声そのものをコピーするものではありません。どの素材があるか、その素材のどの時間を使うか、検索用の言葉や役割を覚えておくための小さなデータベースです。

素材フォルダごとにカタログを一つ使います。

## 使い方

1. `NEW` を押し、動画・音声が入った素材フォルダを選びます。
2. アプリが、そのフォルダ直下に `material-catalog.sqlite` を作り、素材を探します。
3. `区間を登録` で、使いたい素材と開始・終了時刻、検索語、役割を保存します。
4. 次回は `OPEN` で、その `material-catalog.sqlite` を選びます。保存した区間と検索語を続きから使えます。
5. 素材を追加・変更・移動・削除した後は、更新アイコンで再走査します。

`DEMO` も同じ仕組みです。`demo/` を素材フォルダとして使い、初回だけ `demo/material-catalog.sqlite` を作ります。

## カタログが覚えるもの

| 種類 | 例 |
| --- | --- |
| 素材 | `materials/01-1080p-h264.mp4`、ファイルの内容を確かめるための指紋、利用できるかどうか |
| 区間 | その素材の 0 ms から 1000 ms |
| 区間の情報 | 文字起こし、検索語、タグ、役割、メモ |

保存した区間は、GUIDEから候補を作るときに使います。候補から保存する `composition-manifest.json` は、完成した構成の書き出しであり、カタログとは別のファイルです。

## 素材が変わったとき

再走査で現在のフォルダを確認します。

- 新しい素材は追加します。
- 同じパスの素材の内容が変わっていたら、その素材の区間を「要確認」にします。
- 素材を移動または削除したら、以前の素材と区間を「利用不能」にします。
- 元の場所に同じ素材を戻せば、以前の区間を再び使えます。

利用不能・要確認の区間は、GUIDEの候補には使いません。アプリが移動先を勝手に探したり、素材をコピーしたりはしません。

## いましないこと

- 動画や音声の再生
- 長さやコーデックの確認
- 文字起こし、タグ、区間の自動作成

開始・終了時刻は外部プレイヤーで確認して入力します。自動解析は後続の機能です。

## 補足

カタログとして開けるのは、このアプリが作成したSQLiteファイルだけです。別のSQLiteファイルや古いJSON形式のカタログは開けません。
